## (B) What Rubrik Does + Why It Matters to AI
**Plain English:** Rubrik sells a cloud-native "cyber resilience" platform — Rubrik Security Cloud (RSC) — that continuously backs up an enterprise's entire data estate (on-prem, cloud, SaaS like M365/Google Workspace, databases, even GitHub/Azure DevOps code repos) into **immutable, append-only snapshots** that ransomware cannot encrypt or delete, then layers AI-driven threat/anomaly detection, ransomware investigation, cyber recovery, and data-security-posture (DSPM) on top. It now brands itself the **"Security and AI Operations Company"** (SiliconANGLE, Jun 9, 2026) and sells agent-governance products (Rubrik Agent Cloud, Agent Identity, Agent Rewind) to secure AI agents themselves.

**Who buys it:** Enterprise CTOs, CISOs, and increasingly CIOs/boards — data-heavy verticals (finance, healthcare — incl. AHA preferred-provider deal covering ~5,000 member hospitals, energy, government, tech). Sold via channel partners (resellers/SIs) with 3-year subscription contracts.

**Why it matters to the AI sector:** AI runs on data — models, training sets, and proprietary customer data are now the crown jewels (and the #1 ransomware/agentic-attack target). Rubrik is the data-security layer of the AI buildout: it (1) protects the raw material, (2) detects machine-speed attacks on it via AI anomaly detection, (3) knows where sensitive data lives *before* it's fed to a model (Laminar DSPM), and (4) governs the AI agents that now write/deploy code (Agent Cloud / SAGE / Agent Identity / Agent Rewind). Rubrik Zero Labs: 86% of security leaders expect AI agents to outpace their guardrails within a year; 88% worry about meeting recovery-time objectives as agentic threats grow (SiliconANGLE, Jun 9, 2026).

## (C) The Moat (verified, concrete)
1. **Immutability — a structural, not marketing, difference.** Proprietary append-only/zero-trust architecture: backup data can't be modified, deleted, or encrypted by an attacker; no open network protocols exposed on backup data; quorum authorization to change retention; logical air gap. Codebase Resilience extends this to code repos (immutable snapshots of GitHub/Azure DevOps stored outside the repo — "ransomware rollback for code"). Legacy backup vendors bolt security onto engines built for accidental deletion, not adversaries. (10-Q risk factors + SiliconANGLE Jun 9; prior repo research brief corroborates architecture details.)
2. **AI-native defense AND offense.** Anomaly Detection + Ransomware Investigation + Ruby (gen-AI assistant) + Rubrik AI (agentic platform, launched Forward 2026: "Today, Rubrik becomes an agent") — multi-step recovery sequences that used to take human teams weeks now run autonomously with auditable, attributable, reversible actions. SentryAI for system-health monitoring. This is the "machine-speed defense for machine-speed attacks" story.
3. **Land-and-expand subscription economics.** Subscription ARR $1.57B (+32% YoY), average subscription dollar-based net revenue retention **~120%**, 2,946 customers with $100K+ ARR (+24% YoY), ARR contribution margin swung from 8.0% → 13.2% in a year, 80.6% gross margin, 19% FCF margin. Platform consolidation (backup → threat analytics → DSPM → cyber recovery → identity → agents) is the expansion flywheel.
4. **DSPM + agent governance = the AI-era gatekeeper.** Laminar (acquired 2023, ~$250M reported) = "know where your sensitive data lives BEFORE you feed it to an AI model." SAGE (Semantic AI Governance Engine) + Agent Identity (grant access one tool call at a time, Black Hat Aug 2026) + Agent Rewind ("industry's only" action-rewind for agents) + Claude config drift-monitoring (CLAUDE.md, system prompts, tool permissions) = governance over the agentic AI estate. Anthropic partnership (Project Glasswing / Mythos Preview, June 2026) plus Agent Cloud for Claude Code/Cowork GA (June 2026) with 6 global SIs (Cognizant, Deloitte, LTM, HCLTech, NTT Data, Wipro) reselling it.

**Competitive frame (verified directionally):** Veeam/Commvault = legacy backup with security bolted on, sold to IT ops budget; Cohesity-Veritas merged (late 2025, Nvidia-backed, IPO-bound ~$17B per prior repo research) = scale rival in data protection; CrowdStrike/Palo Alto = prevention/endpoint/identity — they don't own clean recovery of the data estate (Rubrik actually partners with CrowdStrike on identity resilience). Rubrik's recovery layer is where money moves when prevention fails.
